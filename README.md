# 青梅市 車観光マップ

青梅市を車で観光する利用者のための、スマートフォン優先の観光スポットマップです。

## 管理者の更新方法

観光情報はGoogle Sheetsの`スポット管理`シートで管理します。

1. `20260828_ome-car-tourism-master-sample.xlsx`をGoogle Sheetsへインポートする。
2. `apps-script/20260828_tourism-data-api.gs`を、対象シートのApps Scriptへ貼り付ける。
3. Webアプリとしてデプロイし、「自分として実行」「全員（匿名ユーザーを含む）」の閲覧設定で`/exec` URLを発行する。
4. `20260828_map-config.js`の`sheetApiUrl`へ、そのURLを一度だけ設定する。

### 住所から座標を取得する

`スポット管理`の`住所`へ住所を入力し、`座標取得`列へ`取得`と入力します。シートを再読み込みすると表示される`地図管理`メニューから「住所から座標を取得」を実行すると、`緯度`・`経度`へ結果が入り、`座標取得`は`完了`になります。住所が不足している場合は`住所要確認`、見つからない場合は`該当なし`になります。

以後はGoogle Sheetsの行を追加・編集し、`公開状態`を「公開」にするだけで地図へ反映されます。`下書き`と`非公開`はアプリに表示されません。

## 既存会員台帳の扱い

会員名簿の担当者名、代表者名、携帯電話番号、メールアドレス、会費・加入・退会情報はマップへ移しません。店舗・施設として掲載許可を得た情報だけを、観光客向けに確認・編集して登録します。

## 車ルート

スポット詳細の「Google マップで車ルートを開く」は、端末のGoogle マップで自動車ルートを開きます。既存のCloudflare Workerは自転車ルートを返すため、このアプリでは使用しません。
